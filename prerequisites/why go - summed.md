3 main reasons why golang is preferred: 
- Development: Go is stupidly simple with very less features - no classes, no inheritance, no try catch (basic features are only there)
- Deployment: No python versioning and requirements to install and no need to deal with mismatches, just deploy a binary file required, and you are good to go
- Concurrency: Python uses - threading, multi-processing or asycnio for development, but Go uses simple goroutines and channels for communication and async activities to get true concurrency
