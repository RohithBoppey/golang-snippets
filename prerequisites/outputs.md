There are different ways of formatting the sentences in golang in printf

- %v : prints value of the variable
- %#v : prints in the go syntax format 
    - applicable on strings, i.e. the output is : "Hello World" 
- %T : print the type of the variable

- %s : to format the value as simple string.
- %q : to print 

- %.2f : print a float variable with only 2 decimal values
